Telegram бот для управления личными проектами.
Позволяет сохранять проекты, добавлять к ним навыки, изменять информацию и удалять проекты.

🚀 Возможности

Бот поддерживает следующие функции:
    •    ➕ Добавление нового проекта
    •    📂 Просмотр списка проектов
    •    🛠️ Добавление навыков к проекту
    •    ✏️ Изменение информации о проекте
    •    🗑️ Удаление проекта
    •    🔎 Просмотр информации о проекте по его имени

📜 Команды бота

Команда    Описание
/start    запуск бота
/info    список команд
/new_project    добавить новый проект
/projects    посмотреть все проекты
/add_skill    добавить навык к проекту
/update_projects    изменить информацию о проекте
/delete    удалить проект

Также можно просто ввести название проекта, чтобы получить информацию о нем.

⚙️ Установка
    
Установите Python (3.9+)
Установите библиотеку для Telegram бота

pip install pyTelegramBotAPI

    
Клонируйте проект или скачайте файлы.
Создайте файл config.py и добавьте токен бота:

TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
DATABASE = "database.db"

▶️ Запуск бота

Запустите файл:

python bot.py

После запуска бот начнет работать через Telegram polling.
